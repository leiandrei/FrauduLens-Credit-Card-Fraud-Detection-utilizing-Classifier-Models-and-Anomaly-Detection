## Initial Model Creation
This directory contains Jupyter Notebooks for the initial model creation for all the selected classifier models such as Logistic Regression, K-Nearest Neighbors, Random Forests, Linear SVC, and an anomaly detection model using isolation forest. 

## About this Section
This section demonstrates model creation, confusion matrices, classification reports, and utilizing dataset sampling through SMOTE (Synthetic Minority Over-sampling Technique) because of the class imbalance of the target feature within the dataset which can be seen through the EDA section.
